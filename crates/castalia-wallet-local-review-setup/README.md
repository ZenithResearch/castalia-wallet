# Fixed local review owner setup

This excluded companion crate creates the finite Process-Pilot authority layout through native Wallet/secS APIs. It has no private-key read/export, generic signing port, service-start command, run-creation command or automatic partial-state reset. The existing native raw-file custody profile remains owner-private file custody; it is not an encrypted vault or membership credential.

The only CLI form is `castalia-wallet-local-review-setup create --plan /absolute/private/plan.json --plan-sha256 <exact-lowercase-SHA256>`. The closed `castalia.wallet-local-review-setup.v1` plan binds the private Process-Pilot root, not_before/not_after decimal strings within one hour, fixed result_opcode `e0`, composition/source-manifest hashes and exact Wallet/result/verifier executable hashes. The selected composition is the fixed nine-operation local review with its committed Runtime version, actor/route/resources, source blobs and supplied transcript/snapshots. This tool cannot select arbitrary paths, operations, roles or providers through browser arguments.

It requires absent authority state and writes an intent before creating separate command issuer, result party and Frank holder identities through native APIs. It selects the current immutable Native export, preserves exclusive final-time/current-Wallet checks, emits the explicit finite512-row command-journal profile, and commits the seven exact configuration hashes plus master/COMPLETE last. It preserves partial state on any failure; reentry is denied rather than silently rekeying. Setup success reports configured_not_activated; no service or run is created.

Build/test with `cargo build --locked --offline --manifest-path crates/castalia-wallet-local-review-setup/Cargo.toml --all-targets` and `cargo test --locked --offline --manifest-path crates/castalia-wallet-local-review-setup/Cargo.toml`. The hostile-json-features profile, strict Clippy and cargo fmt checks are also required. Physical-Mac default/hostile tests each pass18controls; these are disposable custody/API checks and do not establish installed authority, a live provider or useful speech/STT. Installer receipts and owner activation are separate.
